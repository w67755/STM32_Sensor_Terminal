# STM32 Sensor Terminal

## 项目简介

基于 STM32F103C8T6 和 STM32 标准外设库（SPL）开发的传感器终端项目，用于读取 MPU6050 数据，并通过 OLED 和串口显示。

## 当前功能

- 通过硬件 I²C 与 MPU6050 通信
- 读取 MPU6050 设备 ID、三轴加速度和三轴角速度
- 上电时采集静止样本，计算陀螺仪零偏
- OLED 显示加速度和角速度，可通过按键切换页面
- USART1 向电脑串口助手发送六轴数据
- 加速度数据换算为 `g`，角速度数据换算为 `dps`

## 开发环境

- MCU：STM32F103C8T6
- IDE：Keil MDK-ARM 5
- 库：STM32 标准外设库（SPL）
- 传感器：MPU6050
- 显示屏：OLED

## MPU6050 陀螺仪零偏记录

### 初始测试记录（2026-10-17）

- 陀螺仪量程：±2000 °/s（`MPU6050_GYRO_CONFIG` 写入 `0x18`）
- 当时静止显示读数：GX ≈ -0.91 °/s，GY ≈ -0.12 °/s，GZ ≈ -0.54 °/s
- 当时估算的原始偏差：GX ≈ -15，GY ≈ -2，GZ ≈ -9（原始计数）
- 当时使用的固定补偿值：

```c
GX += 15;
GY += 2;
GZ += 9;
```

以上是初始测试记录。当前程序改为上电采样并计算陀螺仪零偏。校准期间应将开发板平稳放置，不要触碰或移动。

## 串口数据输出（2026-10-19）

- 串口：USART1
- 参数：9600 波特率、8 位数据位、无校验、1 位停止位（8N1）
- 接线：STM32 PA9（USART1_TX）连接 USB 转串口模块 RXD，两者共地
- 加速度单位：`g`
- 角速度单位：`dps`
- 角速度数据发送前进行零偏补偿
- 六轴数据以文本形式输出，字段间用逗号分隔，每组数据以换行结束

输出示例：

```text
AX=-0.04g, AY=+0.00g, AZ=+1.08g, GX=+0.12dps, GY=-0.08dps, GZ=+0.31dps
```

## ADC 采集准备（2026-10-20）

- 编写 ADC1 初始化函数 `AD_Init()` 和单通道读取函数 `AD_GetValue()`。
- ADC 配置为独立模式、右对齐、单次软件触发转换，并执行 ADC 校准。
- ADC 时钟使用 PCLK2 分频 6。
- 将 PA1~PA2 配置为模拟输入；目前计划使用 PA2 读取热敏电阻模块 AO，PA1 读取光敏模块 AO。
- 当前 ADC 程序可读取原始转换值；传感器读数显示、单位换算和硬件验证仍待完成。
- 计划将 OLED 页面显示代码整理到独立的 `SensorPage.c/.h` 模块，主循环保留按键切页和数据读取调用。
- 暂不加入红外模块；后续考虑使用 DHT11 增加温湿度测量。
