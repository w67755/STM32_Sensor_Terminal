# STM32 Sensor Terminal

## 项目简介

基于 STM32F103C8T6 和 STM32 标准外设库开发的传感器终端项目。

## 当前功能

- MPU6050 硬件 I²C 通信
- 读取 MPU6050 的设备 ID
- 读取三轴加速度和三轴陀螺仪原始数据
- OLED 显示传感器数据

## 开发环境

- MCU：STM32F103C8T6
- IDE：Keil MDK-ARM 5
- 库：STM32 标准外设库（SPL）
- 传感器：MPU6050

## MPU6050 陀螺仪静止零偏记录

- 记录日期：2026-10-17
- 陀螺仪量程：±2000 °/s（`MPU6050_GYRO_CONFIG` 写入 `0x18`）
- 静止显示读数：GX ≈ -0.91 °/s，GY ≈ -0.12 °/s，GZ ≈ -0.54 °/s
- 根据当前灵敏度换算得到的初始原始偏差估值：GX ≈ -15，GY ≈ -2，GZ ≈ -9（原始计数）
- 当前补偿：读取数据后分别给 GX、GY、GZ 加上 15、2、9；静止时 OLED 显示约 `0.00 °/s`

```c
GX += 15;
GY += 2;
GZ += 9;
```

以上偏差是本次静止测试得到的初始补偿值，会受模块个体和温度影响。更换传感器或环境温度变化较大时，应重新静止测量并校准。

## 2026-10-19：MPU6050 串口数据输出

### 完成功能

- 初始化 STM32 USART1，使用 9600 波特率、8 位数据位、无校验、1 位停止位（8N1）。
- 通过 USART1 向电脑串口助手发送 MPU6050 六轴数据。
- 加速度数据换算为 `g`，角速度数据换算为 `dps`。
- 角速度数据在发送前进行零偏补偿。
- 数据以文本形式输出，字段之间使用逗号分隔，每组数据以换行结束。

### 接线与串口设置

- STM32 PA9（USART1_TX）连接 USB 转串口模块 RXD。
- STM32 与 USB 转串口模块共地。
- 串口助手设置：9600 波特率、8 位数据位、无校验、1 位停止位。
