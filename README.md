# STM32 Sensor Terminal

基于 **STM32F103C8T6** 和 **STM32 标准外设库（SPL）** 实现的多传感器终端。项目读取 MPU6050、热敏电阻和光敏电阻模块的数据，通过按键切换 OLED 页面，并通过 USART1 输出 MPU6050 数据。

## 当前功能

- MPU6050：读取设备 ID、三轴加速度和三轴角速度。
- 陀螺仪校准：上电后采集静止数据并计算零偏；校准期间保持开发板静止。
- OLED 显示：按键在加速度、角速度、热敏电阻 ADC、光敏电阻 ADC 和 DHT11 温湿度页面间切换。
- ADC：读取热敏电阻和光敏电阻模块的模拟输出，并显示 ADC 原始值。
- DHT11：读取并显示温度（°C）和相对湿度（%RH），按约 2 秒间隔更新。
- USART1：以文本格式周期性输出 MPU6050 六轴数据。

> 热敏电阻和光敏电阻页面显示的是 ADC 原始值，尚未转换为摄氏温度或照度。DHT11 的温度和湿度由其数字通信协议直接读取，不使用 ADC。

## 硬件与开发环境

- MCU：STM32F103C8T6
- IDE：Keil MDK-ARM 5
- 外设库：STM32 Standard Peripheral Library（SPL）
- 姿态传感器：MPU6050
- 温湿度传感器：DHT11
- 模拟传感器：热敏电阻模块、光敏电阻模块
- 显示屏：OLED
- 调试输出：USB 转串口模块


MPU6050 与 OLED 的接线按各自驱动文件中的 GPIO 配置连接。按键使用的引脚应与 `Key.c` 中的配置一致。

## OLED 页面

按键依次切换以下页面，最后一页后返回第一页：

1. 三轴加速度（单位 `g`）
2. 三轴角速度（单位 `dps`）
3. 热敏电阻 ADC 原始值
4. 光敏电阻 ADC 原始值
5. DHT11 温度和湿度

## 串口设置

- 串口：USART1
- 波特率：9600
- 数据位：8
- 校验位：无
- 停止位：1（8N1）
- 数据格式：六轴数据以文本形式输出，字段以逗号分隔，每组数据以换行结束。
- 加速度以 `g` 表示；角速度以 `dps` 表示，发送前进行陀螺仪零偏补偿。

输出示例：

```text
AX=-0.04g, AY=+0.00g, AZ=+1.08g, GX=+0.12dps, GY=-0.08dps, GZ=+0.31dps
```

## 运行说明

1. 使用 Keil 打开 `project.uvprojx` 并编译、下载。
2. 上电后让开发板静止，等待陀螺仪零偏校准完成。
3. 观察 OLED 数据，并按键切换传感器页面。
4. 使用串口助手按上述参数连接 USART1，查看 MPU6050 数据输出。

## 目录结构

- `Hardware/`：MPU6050、OLED、按键及 DHT11 等外设驱动。
- `Library/`：STM32 标准外设库文件。
- `System/`：系统延时等基础功能。
- `User/`：主程序和中断文件。
