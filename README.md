# STM32 Sensor Terminal

## 项目简介

基于 STM32F103C8T6 和 STM32 标准外设库开发的传感器终端项目。

## 当前功能

- MPU6050 硬件 I²C 通信
- 读取 MPU6050 设备 ID、三轴加速度和三轴角速度
- OLED 显示加速度和角速度，可通过按键切换页面
- 上电时对陀螺仪进行静止零偏校准
- USART1 向电脑串口助手输出六轴数据
- 串口数据换算为 `g` 和 `dps`，并以文本形式发送

## 开发环境

- MCU：STM32F103C8T6
- IDE：Keil MDK-ARM 5
- 库：STM32 标准外设库（SPL）
- 传感器：MPU6050
- 显示屏：OLED
